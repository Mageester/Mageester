# Hi, I'm Aidan 👋

Co-founder of **[Axiom Web](https://getaxiom.ca)**, a two-person web studio in Kitchener-Waterloo, Ontario, with my partner Riley. We design, build and fix websites for small businesses and agencies, and we build the systems that run behind them.

### What I work on
- **Websites that load fast and convert**: business sites, landing pages and redesigns, hand-coded or on WordPress, Shopify and Squarespace
- **Fixes on sites that already exist**: page speed, layouts that break on phones, accessibility (WCAG 2.1 AA), and forms that never deliver the enquiry
- **The systems behind a business**: email and outreach automation, internal dashboards, Cloudflare Workers, Notion and calendar integrations
